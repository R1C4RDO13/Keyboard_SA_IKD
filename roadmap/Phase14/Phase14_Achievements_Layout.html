MoodScript Phase 14 · Achievements layout — per-group carousel · 2026-05-17

The Achievements tab is a vertical list of group rows. Each row shows one centred focus card — the group's current in-progress badge — with ‹ / › buttons and swipe to page through that group's other badges (page dots show position). The Daily-devotion group adds a "mini-keyboard" 14-day strip (filled = a day with ≥ 3 intentional mood logs) so the strict consecutive-streak rule is legible. The tab is always all-time — the global Range/Mood filters don't apply here. v1 = 28 badges across 5 groups. Try the arrows.

Per-group carousel — focus card defaults to the next badge to earn. Arrows / swipe page within a group.

How a group row works

  • Focus card = first not-yet-unlocked badge in the group (the "what you're working toward"); if all unlocked, the last tier.
  • ‹ / › + horizontal swipe move within the group; page dots show index. Arrows disable at the ends. Built as a nested ViewPager2 per group row.
  • Group header: primary-tinted, with unlocked / total.
  • Vertical list scrolls between groups; each group keeps its own carousel position.

Daily-devotion = strict streak

A badge needs N consecutive days each with ≥ 3 intentional mood logs. A missed day resets the run (longest run ever is used, so it never re-locks). The 14-day strip under that group's card shows hit (filled) vs. miss (dim) days — today is the outlined rightmost cell — so the user sees exactly where a streak broke.

Card states

  • Unlocked — full-colour, glow border (badge_unlocked_glow), unlock date, no bar.
  • Locked + progress — greyscale emoji, faded surface, ProgressBar + grouped current / target caption.
  • Locked, boolean — no bar. None in v1 (only mood_returner, deferred group 2).
