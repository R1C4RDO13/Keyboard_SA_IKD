## Concept

A donut (or stacked horizontal bar) showing the share of typing sessions by phone orientation across the selected range. Surfaces `SessionRecord.orientation` for the first time since Phase 2 stored it. Combined with the 9.4 Mood Filter, answers "*do I type lying down more when I'm sad?*".

Sits inside the **Keystroke Dynamics** section (introduced in 9.7) — see [orchestrator Decision #17](../Phase9_Plan.md#cross-cutting-decisions). Beneath the three histograms.

## Orientation int → label map

The orientation int comes from the `Configuration.ORIENTATION_*` family that `LiveCaptureSessionStore` already captures. Plus the Phase 2 sentinel.

| `orientation` value | Label string key | When |
|---|---|---|
| `1` (`Configuration.ORIENTATION_PORTRAIT`) | `orientation_portrait` | normal upright |
| `2` (`Configuration.ORIENTATION_LANDSCAPE`) | `orientation_landscape` | rotated |
| `0` (`Configuration.ORIENTATION_UNDEFINED`) | `orientation_unknown` | OS reported undefined |
| `-1` (Phase 2 sentinel) | `orientation_not_captured` | `Config.captureOrientation == false` for that session |
| any other | `orientation_unknown` | future-proofing |

Face-up / face-down labels in `strings.xml` are present for forward compatibility — the current capture path doesn't emit them, but the layout shouldn't break if a future capture-side change adds them.

## Donut UI spec

- Hole radius: 60% (donut, not pie). Centre text = `"<n> sessions"` (total across slices) on top, `<X.X> min` (total typing time) below.
- Each slice tinted from the orientation colour palette. **No hex literals in Kotlin** ([orchestrator Phase-6 lesson note](../Phase9_Plan.md#cross-cutting-decisions)).
- Legend: horizontal `LinearLayout` of one row per orientation slice with `> 0` sessions. Missing orientations are omitted (no zero-row entries).
- Built-in MPAndroidChart legend disabled — we draw our own.
- Sentinel `-1` ("Not captured") is shown only when at least one session in the range has that value.

---

## Empty state

When no sessions captured orientation in the range (every session has `orientation = -1`), the entire card is `View.GONE`. The Keystroke Dynamics section header is `View.GONE` only when *all* its child cards (three histograms + this donut) are hidden.
