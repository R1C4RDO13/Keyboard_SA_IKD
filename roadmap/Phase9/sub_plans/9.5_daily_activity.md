## Concept

Two complementary widgets that answer "*when did I type this month?*":

1. **Calendar Heatmap** — pattern view. Rows = ISO week-of-year, columns = day-of-week, cell intensity = total keystrokes that day. GitHub-contributions-style.
2. **Daily Keypress Bar Chart** — volume view. One bar per day in the selected range, height = total keystrokes.

Both live in a new **Daily Activity** section between **Trends** and **Mood**.

## SQL

```sql
SELECT
    strftime('%Y-%m-%d', timestamp / 1000, 'unixepoch', 'localtime') AS day,
    COUNT(*) AS keystrokeCount
FROM ikd_events
WHERE event_category != 'AUTOCORRECT'
  AND timestamp >= :fromMs
  AND timestamp <  :toMs
  AND (:moodScore IS NULL
       OR session_id IN (SELECT session_id FROM mood_entries WHERE mood_score = :moodScore))
GROUP BY day
ORDER BY day
```

Worst case: 30 rows for Month range, 90 rows for All Time at default 90-day retention.

## Calendar Heatmap UI spec

- Layout shape: `52 rows × 7 columns` for All Time (full year), `5 × 7` for Month, `1 × 7` for Week. Activity computes the row count from the `Range`.
- Cell size: `heatmap_cell_min_size_dp` rounded; container width / 7 for the actual cell width (responsive).
- Y axis labels: month abbreviation on the first row of each month ("Jan", "Feb", …). X axis labels: `M T W T F S S`.
- Tap on a cell → toast `"<date>: <n> keystrokes"`. No navigation, no detail screen ([orchestrator Decision #24](../Phase9_Plan.md#cross-cutting-decisions)).
- Empty cells (zero keystrokes) render at 5% alpha — visible scaffold but not noisy.
- Legend strip beneath the grid: small swatch row showing `0 → low → mid → high → max` count gradient.

## Daily Keypress Bar UI spec

- One bar per day in the selected range. Y = keystroke count. X labels follow the existing `formatBucketLabel(...)` helper.
- Bar colour: `getProperPrimaryColor()`. No fade.
- Empty days render as zero-height bars (kept on the X axis for alignment with the calendar heatmap row above).
