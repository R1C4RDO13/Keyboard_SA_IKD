## Concept

A new **Habits** section beneath the Mood section with one KPI strip + four trend line charts. The strip surfaces all-time-style numbers scoped to the selected `Range`; the four charts split the range into the standard daily/weekly buckets and answer "how have my typing habits trended over time."

| KPI cell | Source | Format |
|---|---|---|
| Total sessions | `sessionBuckets.sumOf { sessionCount }` | integer |
| Total typing time | `sessionBuckets.sumOf { totalDurationMs }` | minutes, one decimal |
| Avg session duration | `totalDurationMs / sessionCount` | seconds, one decimal (or "—" when no finished sessions) |
| Longest streak | `Companion.computeLongestStreak(buckets)` | integer + "days" / "weeks" suffix from the range |

| Trend chart | Y axis | Source per bucket |
|---|---|---|
| Avg Session Duration | minutes | `totalDurationMs / sessionCount` |
| Sessions per Day / Week | sessions | `sessionCount` |
| Avg Error Rate | % | `100 * correctionWeight / keystrokeCount` (Phase 7.1 formula) |
| Avg Flight Time | ms | `avgFlightMs` |

## Streak edge cases (Decision #9 in the orchestrator)

For `Range.WEEK` and `Range.MONTH` the bucket key is `%Y-%m-%d`; the streak counts consecutive **days** with `sessionCount > 0`. For `Range.ALL_TIME` the key is `%Y-%W` and the streak counts consecutive **weeks**. The `HabitsSnapshot.streakUnit: StreakUnit` enum carries this so the activity's KPI label code is one `when` block.

`Companion.computeLongestStreak(buckets)` walks the bucket list (already in ascending key order from SQL `ORDER BY`), counts maximal runs of `sessionCount > 0`, returns the max. Pure — no I/O, no instance state.

---

## Chart-empty rules

- **Avg Session Duration** — null bucket when `sessionCount == 0` (line break).
- **Sessions per Day / Week** — zero is meaningful, so render zeros as bars; only render null when the SQL returns no row at all for that bucket key.
- **Avg Error Rate** — null when `keystrokeCount == 0`.
- **Avg Flight Time** — null when no rows in the bucket have `flight_time_ms >= 0` (handled SQL-side by `AVG(CASE WHEN flight_time_ms >= 0 THEN flight_time_ms END)`).
