# Phase 9.12 — Theming, top tabs, global KPI dedup

**Sub-phase of:** [Phase 9 Orchestrator](../Phase9_Plan.md)
**Implementation order:** 12 of 12 — three-issue follow-up after Phase 9.11.
**Branch context:** Lands directly on `main` — no feature branch.

---

## Why

Three follow-up issues raised after Phase 9.11 shipped (`eb8454f2`, `f00b5713`, `be4d98ba`):

1. **Theming gap** — the user-selected Fossify keyboard theme didn't reach the new fragment surfaces. `FragmentStateAdapter` recreates each tab's view on attach; tab labels, fragment text and `MaterialCardView` slabs rendered in default Material colours.
2. **NavigationRail placement** — the user wanted the tab strip on **top**, styled identically to the existing range toggle, not on the left edge as a vertical rail.
3. **Habits KPI strip duplication** — three of four cells in the per-tab Habits KPI strip duplicated cells already on the global KPI strip.

## Decisions

| # | Topic | Decision |
|---|---|---|
| 1 | Theming hook | Per-fragment `updateTextColors(view.root)` + a host-side `FragmentLifecycleCallbacks.onFragmentViewCreated` that re-themes and re-renders. Both required: the lifecycle callback covers the first-attach case before render fires; the per-render call covers theme switches happening between renders. |
| 2 | Tab styling | Same `?attr/materialButtonOutlinedStyle` as the range toggle — the user asked for "styled identically". `applyToggleGroupColors` runs on both groups in `onResume`. |
| 3 | Tab labels | Two long names (Daily Activity, Keystroke Dynamics) abbreviated to "Activity" / "Keystrokes" to keep buttons visible on narrow phones; the toggle is wrapped in a `HorizontalScrollView` regardless so even the abbreviated labels can scroll horizontally if the user's font scale enlarges them. |
| 4 | KPI strip cell count | 6 (Sessions, Typing time, Avg WPM, Error rate, Avg session duration, Longest streak). Wrapped in a `HorizontalScrollView` because 6 cells overflow a 360dp screen. Each cell is `wrap_content` with a `minWidth` so the scroller has natural break points. |
| 5 | Streak under TODAY | Continues to render as "Today" / "—" via `StreakUnit.HOURS`, unchanged from Phase 9.11. |
