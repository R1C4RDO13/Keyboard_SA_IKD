## Concept

A scatter chart with X = backspaces for the day, Y = autocorrection count for the day, one bubble per day in the selected range. The most-recent day rendered larger and at full alpha; older days fade linearly to ~20% alpha across the date range. Pairs naturally with the 9.4 Mood Filter — *"when I tag Anger, do I cluster further from the origin?"*

Lives **inside the Habits section** (introduced in 9.3) — see [orchestrator Decision #17](../Phase9_Plan.md#cross-cutting-decisions). Sits beneath the four Habits trend charts.

## SQL

```sql
SELECT
    strftime('%Y-%m-%d', timestamp / 1000, 'unixepoch', 'localtime') AS day,
    SUM(CASE WHEN event_category = 'BACKSPACE'   THEN 1 ELSE 0 END) AS backspaceCount,
    SUM(CASE WHEN event_category = 'AUTOCORRECT' THEN 1 ELSE 0 END) AS autocorrectionCount
FROM ikd_events
WHERE timestamp >= :fromMs
  AND timestamp <  :toMs
  AND (:moodScore IS NULL
       OR session_id IN (SELECT session_id FROM mood_entries WHERE mood_score = :moodScore))
GROUP BY day
ORDER BY day DESC
```

Worst case: 30 rows for Month range, 90 rows at default retention. The `ORDER BY day DESC` puts the most-recent day at index 0, which makes the `dayIndex` assignment in `Companion.buildSnapshot` a one-line `mapIndexed`.

## Scatter UI spec

- One circle per day. X = `backspaceCount`, Y = `autocorrectionCount`.
- **Most-recent day** (`dayIndex = 0`): `getProperPrimaryColor()` at full alpha (255), 1.8× radius.
- **Older days** (`dayIndex > 0`): `getProperPrimaryColor()` at decreasing alpha — linear fade from 80% (oldest visible) → 20% (just before today). Radius 1.0× (smaller than the recent point).
- Tap on a point → `Toast` with the date and counts.
- Built-in MPAndroidChart `Description` and right-axis disabled.

### Subtitle copy (preserved verbatim from the deleted Phase 11 spec)

> *"When our mind is clear we tend to make fewer typing errors and require less backspace usage. On such days, the most recent data point will be closer to the origin."*

Rendered as a `MyTextView` with `textSize = @dimen/smaller_text_size` and `textStyle = italic` below the chart.

## Empty state

When the range has no events with `event_category` in (`BACKSPACE`, `AUTOCORRECT`), the card is `View.GONE`. (Edge case: a brand-new install with only ALPHA events — possible but unusual.)
